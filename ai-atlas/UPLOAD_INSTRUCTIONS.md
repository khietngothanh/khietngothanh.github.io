# AI Atlas – Hướng dẫn tải website lên

Thư mục này dành riêng cho website AI Atlas. Website gốc tại `/` và ứng dụng khác trong repository được giữ nguyên.

1. Tải và giải nén `AI-Atlas-GitHub-Pages(2).zip` từ cuộc trò chuyện ChatGPT.
2. Vào thư mục `ai-atlas` trong GitHub, chọn **Add file → Upload files**.
3. Kéo thả tất cả 9 file (`index.html`, `styles.css`, `app.js`, `course-data.js`, `engineering.js`, `glossary.js`, `resources.js`, `.nojekyll`, `README.md`) vào **chính thư mục này**, không tạo thư mục con.
4. Chọn **Commit changes** vào nhánh `main`.
5. Nếu GitHub Pages đã bật từ nhánh `main` và thư mục `/(root)`, truy cập `https://khietngothanh.github.io/ai-atlas/`.

Không upload file liên kết Google Drive riêng hoặc tài liệu có bản quyền vào repository công khai.
